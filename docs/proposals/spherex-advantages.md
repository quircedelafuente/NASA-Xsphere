# What SPHEREx gives us that WiseView never had (14 Nov 2026)

| SPHEREx advantage | WiseView (WISE) | What we can build with it |
|---|---|---|
| **102 infrared colours** (0.75–5 µm): every object gets a spectrum | 2 colours (W1, W2) | **"What is it?"**: classify a mover from its spectrum (brown dwarf: methane dip at 3.3 µm; asteroid; ordinary star), with a confidence |
| **Molecules and ices** (water, CO₂, CO, methane): a SPHEREx mission goal | No | **Ingredient finder**: mark the dips and name the molecules. Comets and icy objects light up (3I/ATLAS spectra exist) |
| **Temperature from the spectrum** | Rough colour only | **3D model dials measured, not guessed** (colour, size from temperature + distance) |
| **New data every week**, 2025–2027 | WISE ended 2024; archive only | **"New this week"** feed; the engine updates by itself; a chance at genuinely new candidates |
| **Many photos within one visit** (a visit spans weeks, ~17 photos per detector) | Yearly merged images only | **Fast-mover mode**: asteroids move a lot within one visit, so blink the photos *inside* a visit |
| **Deep fields near the ecliptic poles**, revisited about monthly | Same cadence everywhere | **Light curves**: R Draconis brightening and fading over a year |
| **Combine with WISE**: 2010 → 2026 | Stops at its own data | **"15 years in one blink"**: WISE then SPHEREx, so slow movers become obvious (Barnard's Star moved about 2.7′) |

**Honest limits:** pixels are 6.15″ (WISE is 2.75″, so sharper). Only 3–4 visits so far. Bright stars saturate. Each photo is a different colour, so photos must be merged per detector before blinking.

**Hackathon top 3** (most impact for the hours): 1) "What is it?" spectrum hint, 2) 15-year WISE + SPHEREx blink, 3) R Draconis light curve.
